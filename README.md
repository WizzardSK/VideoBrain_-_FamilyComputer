# VideoBrain_-_FamilyComputer

Thumbnails for VideoBrain Family Computer software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `vidbrain` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
