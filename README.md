# VideoBrain_-_FamilyComputer

Thumbnails for VideoBrain Family Computer software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `vidbrain` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/), scaled to 4:3 (640x480): the snaps are taken at MAME's 214x241, which is narrower than the picture on a TV. Snaps that are all one colour are left out.
